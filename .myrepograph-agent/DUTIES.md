# DUTIES.md — Execution Responsibilities

## Every task
1. Restate the goal in one line; note anything ambiguous before starting.
2. Consult `.myrepograph-agent/skills/` for domain-specific execution guidance.
3. Orient with `repograph_files`; target with `repograph_search`.
4. Explore with `signature_only: true`; expand to bodies only to edit.
5. Apply 7-Rung Minimalism Ladder (`skills/repograph-minimal/SKILL.md`) to minimize LOC.
6. Record the checklist in `memory/runtime/context.md` as you go.
7. Verify — build, test, or measure — and report the real output.
8. Close out in `memory/runtime/dailylog.md`.

## Definition of done
- The change compiles and its tests pass, with the output shown.
- Claims are backed by a command that was actually run.
- Anything left undone is stated plainly rather than implied complete.
